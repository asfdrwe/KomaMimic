# 表示と画像加工

日本語 | [English](../en/user/views.md)

## 見開きと倍率

表示メニューで単ページ・見開きを選びます。新規設定は右開き・見開き・表紙単ページが有効です。
`Space` は画像の自動見開きを切り替えます。明示的な単ページ／見開きの選択とは区別します。
開く向きはバックスラッシュ（JISキーボードの¥）で切り替えられます。

`X` は画面に合わせる、`C` は原寸、テンキーの+/-は拡大・縮小です。
「スケールモード」で倍率の合わせ方と補間方式を選べます。

## ファイル名とサムネイル

読書画面下部のファイル名は既定で非表示です。「環境設定 → 表示」で有効にできます。
非表示時は専用帯を確保せず、その領域も画像の倍率・パン・走査スクロールに使います。

ページサムネイルの付加連番は既定で非表示です。元のファイル名の数字は残ります。
「表示 → サムネイルの設定…」から連番とカスタム配置を設定します。
カスタムは幅64・高さ64、列数0（幅から自動）、縦横の間隔0、名前1行、左上起点、装飾枠なしが初期値です。
固定列数、幅・高さ、縦横間隔、名前0/1/2行、右上起点、装飾枠の有無を選べます。
0行では名前用領域も除去します。画像は縦横比を保ち、長い名前はツールチップで確認できます。
カスタム配置は表紙・ページ一覧共通で、画面フィット・8列のモードも残ります。

## フォルダブラウザー

上下2ペインが既定です。上段のフォルダをダブルクリック/Enterで開くと、下段ツリーの起点がその場所へ変わります。
この操作では右側の表示を変更しません。下段でフォルダをダブルクリック/Enterすると、右側にその場所の表紙一覧を開きます。
下段で選択しただけでは移動しません。右側で別のフォルダへ移っても、左側の起点や選択は変わりません。

2ペインの最上位はWindowsでは仮想デスクトップ、macOS/Linuxでは仮想「場所」です。
「場所」にはホーム、ダウンロード等の標準フォルダ、ファイルシステム(`/`)、利用可能なボリュームへの入口があります。
Windowsの仮想項目はOSのShellから列挙するため、OSや設定によって内容が変わります。

「環境設定 → 表示」で2ペインを無効にすると従来の1ペインになります。
1ペインの最上位はWindowsではPC（各ドライブ）、macOS/Linuxでは`/`です。選択した表示形式は保存されます。
F3は左側全体の表示を切り替えます。上下の境界はドラッグでき、分割位置も保存します。

## メニューと読書バー

読書用の下部バーは初期状態で非表示です。「表示 → ツールバー表示」または
「環境設定 → 表示」で有効にします。全画面では上端からメニュー、下端から有効な読書バーを
呼び出せます。固定・自動・非表示は環境設定で選びます。
下部バーの左右の操作群と中央のページバーは「操作設定 → ツールバー」で編集します。

## 加工と保存

「ツール → 画像加工」で回転・切抜き・グレースケール・色調などを設定します。
初期状態では加工はオフで、`F` または加工プロファイルの選択で有効にします。
スクリプトfilterはnative加工の後に適用します。

通常の表示加工とページの論理編集は元の画像・書庫を直接変更しません。
結果を残すには保存・書出しを使います。実ファイルの改名やごみ箱への移動は別の操作です。
クリップボードから作った本も、必要なら終了前に書き出してください。
PDF出力はラスタ画像となり、元PDFの文字検索情報やリンクは残りません。
文書ビューには画像加工・ページ編集・画像としての書出し・印刷を適用しません。
