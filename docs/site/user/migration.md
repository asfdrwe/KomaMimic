# MangaMeeyaの設定を取り込む

日本語 | [English](../en/user/migration.md)

「ファイル → MangaMeeyaの設定を取り込む…」でINIを選びます。
元のINIは書き換えず、対応が分かっている項目だけを変換します。

1. 対象を、すべて・キーのみ・読書/読込のみ・先読みのみ・読書バーのみから選びます。
2. 現在の値と取り込む値、未対応・競合の理由を確認し、必要な項目を選びます。
3. 適用すると現在の設定をバックアップしてから、選んだ項目を反映します。
4. キーや表示を確認します。再読込が必要な項目は本を開き直してください。

![migration-preview-ja.png](../assets/screenshots/migration-preview-ja.png)

キャンセルでは取り込みもバックアップも行いません。バックアップは設定と同じフォルダの
`KomaMimic-before-MangaMeeya-XXXXXX.ini` です。全体を戻すときは終了後にこの内容で
settings.iniを置き換えます。通常の設定インポートによる上書きとは異なります。

主な対象は表示モード、先読み、更新監視、再帰読込、自動見開き/分割の条件、
対応するキー、下部バーの配置です。未知の番号・数値や単位は推測しません。
競合するキーは取り込まず、現在の割当を維持します。

マウス・ゲームパッド、プラグイン、外部プログラム、パス・履歴はこの操作で移行しません。
