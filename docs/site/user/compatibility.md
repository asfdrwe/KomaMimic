# MangaMeeyaとの違い

日本語 | [English](../en/user/compatibility.md)

KomaMimicはMangaMeeyaに着想を得た独立した実装で、完全互換ではありません。
以下は現在確認している相違と代替操作です。将来の対応を約束する一覧ではありません。

| 機能 | 対応・相違 | 代替操作・説明 |
|---|---|---|
| プラグイン・スクリプト | Susie/AviSynth DLLや旧独自スクリプトの互換実行は提供しません | [JavaScript API 1](../scripts/api.md)で画像reader/filterを追加できます |
| 未対応形式 | GCA、バイナリMMT等は互換読込できません | [対応形式と制限](formats.md)を参照してください |
| カスタムサムネイル | 列数、寸法、間隔、名前行数、配置起点、装飾枠に対応します。原作の縮小方式全選択、JPEG間引き設定、cacheの保存形式・専用拡張子・専用保存先、原作cacheの取込は再現しません | [表示と画像加工](views.md)。保存済みcacheの形式・画素の原作との一致は保証しません |
| ソートメニュー | 現行の自然順・名前・種類・サイズ・更新日時・格納順・Unicode順・ランダムを使い、逆順は共通の切替です。原作の全パス順項目を個別再現しません | 下記の保存仕様を参照してください |
| フォルダブラウザー | 2ペインはWindowsで仮想デスクトップ、macOS/Linuxで仮想「場所」が最上位です。ShellやFinderの全機能を再現するものではありません | 任意の1ペインはWindowsでPC、macOS/Linuxで`/`。[操作方法](views.md) |
| 設定移行 | 対応するINI項目だけを変換します。未知の項目・値を推測して適用しません。原作のmouse/gamepad、プラグイン、外部プログラム、パス・履歴等はこの操作では移行しません | [設定の取り込み](migration.md)のプレビューで実際の対象を確認してください |

## ファイルソートと保存

「ツール → ファイルソート」と「環境設定 → 表示」の並び順は、表紙一覧と画像の読書ページで共用する既定設定です。
方式と逆順を保存し、再起動・設定スロット・KomaMimic設定のエクスポート/インポートで復元します。
元のファイルや書庫の内容は変更しません。ソート時は選択中のファイル・読書ページを識別して維持します。
設定の読込をキャンセルした場合は変更しません。

初期値は自然順・逆順OFFです。既存の表紙一覧の明示的な設定値も引き継ぎます。
次に開く画像や書庫にも適用しますが、TXT・Markdown・EPUB本文の章やページをファイル名順に並べ替える機能ではありません。
白紙追加・ページ削除・分割等で編集した構成は自動ソートで崩しません。明示的な並び替えは可能です。
読書中の並び替えをUndoしても、保存した既定設定まで初期化する操作にはなりません。

通常フォルダの表紙一覧ではフォルダを先に表示します。種類・サイズ・日時が同じ場合は自然順を使います。
格納順は書庫ではエントリ順、通常フォルダではOSの列挙順となり、OS間での一致は保証しません。
ランダムは方式だけを保存し、並びそのものや乱数seedは固定保存しません。開き直しや明示的なランダム選択では新しい並びとなり、単なる再描画では再シャッフルしません。
逆順は現在のランダムな並びを反転します。フォルダ優先は維持します。

読書下部のファイル名とサムネイルの付加連番は、既定で非表示・必要なら有効化できます。
これらの改善済み項目を未対応とは扱いません。設定・cacheの保存方法は[設定とキャッシュ](settings.md)を参照してください。
