# 更新履歴

日本語 | [English](en/changelog.md)

## 未リリース

- コマンドラインのページ指定・画像ページ移動後、表示完了を待ってから後続コマンドを実行し、直後の終了で最終表示や履歴の保存が抜けることを防ぎます。
- 文書表示の描画領域を分離し、WebEngine利用で表紙・ページ一覧の描画方式が切り替わることを防ぎます。ビルドに必要なQtを6.8以降へ変更しました。
- 取得済みの表紙・ページサムネイルをメモリでも再利用し、フォルダや表示モードの往復で保存PNGの再読込を抑えます。
- 表紙・ページサムネイルの全件先読み設定を追加しました（既定オフ）。表示を優先し、残りを順に読み込んで容量内でメモリ保持します。先読みの中断・取消とメモリ上限に対応します。
- 文書の可変本文で組方向と見開き順序を連動。EPUBの表紙を中央単ページにし、現在章・必要リソースから準備する。読込取消と直前1冊の表示復帰、読込中の前後移動を改善。
- 青空文庫のWindows形式の相対画像参照に対応。画像だけの区画とキャプションを分離し、横長挿絵を全幅表示。元の本文位置を保持して必要時に画像を読む。
- 読書開始時の非表示サムネイル準備・親フォルダ走査を停止し、モード移動後の旧一覧配送と初期化中の重複画像要求を修正しました。
- 全ファイル一括ロードを保存される読込オプションへ変更しました。読書中だけファイルデータを容量内で保持し、現在表示・通常先読みを優先します。
- 入れ子・フォルダ内書庫の画像を必要時に読み出し、未表示項目の局所エラーが正常ページの表示を妨げる経路とアニメーション取消を改善しました。

## v1.5.0

- 保存済みサムネイルを元ファイルの検査なしで最優先表示します。定期検証を廃止し、具体的な変更の兆候がある対象だけ更新します。採用元とその情報が変わらない追加では再生成・PNG再保存を行わず、未変更画像を保持します。
- フォルダ表紙の追加探索階層数を0～8で設定できます。既定0でも表紙対象フォルダの直下を探し、それより下には進みません。探索を浅くしても保存済み画像を保持します。
- フォルダ・モード移動時に不要な処理を取り消し、現在表示を優先します。読書中は現在表示と先読みに集中し、サムネイル処理を行いません。
- 完成画像の保存待ちはディスク退避・再試行・通常終了後の再開に対応します。容量超過時は保存日時が古い順（FIFO）に整理し、読込では日時を変えません。thumbnails-v2を引き続き利用します。
- キャッシュがない可視画像の生成を優先し、保存完了を待たず表示します。更新失敗では旧画像を維持し、完成したTXT・Markdown・書庫内テキストの表紙プレビューも保存します。

## v1.4.3

- 利用者向けの動作変更はありません。v1.4.2は欠番です。

## v1.4.1

- 環境設定でスクリプト登録先の追加・削除を保存した後、再起動が必要なことを案内します。言語変更も同時に保存した場合は一つの案内にまとめます。
- 表示用キャッシュの整理では画面内のサムネイルを保護し、画面外の古い画像から解放します。

## v1.4.0

- 保存済みの表紙サムネイルを元ZIPのファイル情報取得より先に表示し、バックグラウンドの低優先度処理で更新を確認。変更があれば表紙を再生成して差し替えるよう改善。
- サムネイルキャッシュを `thumbnails-v2` に変更。`thumbnails-v1` のキャッシュは引き継ぎません。旧版のキャッシュ容量を回収する場合は、更新前に旧版の「環境設定 → キャッシュ」で削除してください。
- F6で表紙を再取得でき、環境設定で保存キャッシュを削除できます。サムネイルの寸法はQtの論理ピクセル単位です。

## v1.3.0

- サムネイルのディスクキャッシュから20,000件の件数制限を撤廃し、設定した容量のみで保持件数を制御。書き込みに失敗しても既存のPNGを保持するよう改善。
- アプリ・Qt・スクリプトのバージョン、および無関係なスクリプト設定によるキャッシュの無駄な再生成を削減。キャッシュキー形式が変わったため旧キャッシュは再利用しません。ディスク領域を回収したい場合は「環境設定 → キャッシュ」から消去してください（元画像や読書履歴には影響しません）。
- WindowsでMangaMeeya設定インポート後のINI保存が失敗する問題を修正。

## v1.2.1

- 単一起動設定で再度起動した際、既存ウィンドウの最小化を解除してから前面化を要求するよう修正。最大化・全画面状態と読書位置を保持。

## v1.2.0

- 現在表示する表紙・ページのサムネイルを優先し、保存済みキャッシュの確認を重い画像生成から分離。別の生成処理を待たずにキャッシュを表示。
- 生成した画像は先に表示し、キャッシュの保存・整理と読書の先読みは後続処理として実行。表示対象の変更時には不要になった処理を取り消すよう改善。
- サムネイルモードで非表示の読書画面の画像生成・先読みを停止。選択ページの画像コピーは明示的な操作時に実行。
- フォルダ一覧の読み込み・ソートを非同期化し、一覧更新時の選択とスクロール位置を保持。

## v1.1.1

- 全画面状態を保存し、全画面で終了した場合は次回も全画面で起動するよう修正。通常表示に戻して終了した場合は通常表示で起動。
- 「環境設定 → 表示 → 全画面表示」で現在の表示を変更できる項目を追加。
- 全画面状態を設定スロットと設定ファイルのエクスポート／インポートにも反映。全画面解除時の通常ウィンドウの配置を保持。

## v1.1.0

- 読書画面下部のファイル名とページサムネイルの連番を設定可能にし、既定で非表示に変更。ファイル名の専用領域も画像表示に使用。
- 独立した上下2ペインのフォルダブラウザーを追加して既定に変更。従来の1ペインも選択可能。
- カスタムサムネイルに幅・高さ、列数、間隔、ファイル名行数、配置起点、装飾枠を追加。初期値は64×64・自動列数・間隔0・名前1行・左上・枠なし。
- ツールバーの表示切替を「表示」メニューの直下へ移動。
- 表紙一覧と画像読書ページでファイルソートの既定方式・逆順を共有し、設定スロットと設定ファイルでも保存・復元。取り込んだリスト固有の並び順は開く際に維持。
- フォルダツリーの名前列の幅と、隠し属性の親フォルダを含むパスの選択を修正。
- 青空文庫TXTの画像・キャプション注記と、挿絵付きTXTの限定的なimg参照に対応。文書の単ページ設定が画像用履歴で上書きされる問題を修正。
- サムネイルの保存済みPNGを、保存・整理のロックや全件一覧の走査を待たずに再利用。ロック競合による不要な元画像の再生成を修正。
- 「MangaMeeyaとの違い」を追加し、対応範囲・代替操作と設定の保存仕様を整理。
- Windowsで設定ファイルのエクスポートに失敗する問題を修正。

## v1.0.3

- Linux AppImageで、同梱ライブラリと実機のMesaドライバーの競合により文書表示開始時に異常終了する問題を修正。
- Windowsで、日本語などを含むパスのEPUBを開く処理を修正。
