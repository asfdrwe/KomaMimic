# macOS differences

[日本語](../../user/macos.md) | English

Screenshots on this page show the Japanese UI.

## Keys and menus

| Action | Default on macOS |
|---|---|
| Open the selected list item | Return |
| Full screen | Control+Command+F (⌃⌘F) |
| Preferences | Command+, (⌘,) |

Menus appear at the top of the macOS screen. Preferences, Quit, and related commands
use the standard application menu. Some controls described with Ctrl on Windows/Linux
are displayed and handled with Command on macOS. Check the menu and shortcut
settings rather than replacing every Ctrl with Command.

## Input devices and power

Use the secondary-click action configured on your Mac for right-click operations.
Mouse assignments can be changed in Control settings. Enable display-sleep
inhibition in Preferences to prevent automatic display sleep while reading in the
foreground. It targets automatic display sleep, not every condition that can put
the computer to sleep.
