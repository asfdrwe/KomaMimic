# Bookshelves, history, and bookmarks

[日本語](../../user/library.md) | English

Screenshots on this page show the Japanese UI.

The Book list menu provides history, favorites, playlists, and bookshelves. Choose
a recently opened or registered book from a list to continue from its saved position.

## Registering and resuming

While reading, use Book list to add the book to favorites, a playlist, or a bookshelf.
The same menu provides cover/spine registration and list details, saving, and loading.
Adjust history and resume-position storage under Book list → History and resume
settings…. If you move or delete a real book, entries pointing to its old path may
no longer open it.

Book list also provides the current-position marker and adding/jumping to table-of-
contents entries. Document contents use the book's own table of contents and text
positions, separate from image page numbers.

## Sorting and playback

Tools → File sort offers natural order, name, type, size, date/time, archive order,
and other choices. Folder/cover-list settings control cover-list ordering.
Use Book list → Page and playlist playback to control autoplay. This is separate
from animated-image playback, such as GIF; animation controls are in Tools.

Registrations and history are local reading data. See
[storage locations and backups](settings.md).
