# Native platform validation

After automated tests, check the deployed artifact on its target OS. Test inputs
are original synthetic data generated by
`tests/fixtures/generate_validation_samples.py`. Do not include original MangaMeeya
files or third-party comics and books in public validation kits.

```sh
python3 tools/prepare_validation.py --output ../tmp/validation-kit
python3 tools/prepare_validation.py --verify ../tmp/validation-kit
```

Build the kit's `source/` on the target OS. For the Windows development environment,
see [building](building.md) and the [README](../../README.md). After moving source,
configure a new build instead of copying an old CMakeCache.

```sh
python3 tools/run_validation.py run --build-dir ../tmp/build-native \
  --fixtures ../tmp/validation-kit/fixtures --output ../tmp/results/native-01 \
  --jobs 4 --test-scope full
python3 tools/stage_validation.py --build-dir ../tmp/build-native --output ../tmp/stage-native-01
```

On Windows, set up the Qt/vcpkg environment and use
`--windows-mode prebuilt --test-scope platform`. Use the same deployed executable
and worker for CLI and GUI checks, identifying them by the stage manifest hashes.

## Manual checks

Record the scope and observations in the `manual-guide.md` and `manual.csv` generated
by `run_validation.py`. Select checks appropriate to the change, focusing on:

- Startup without development PATH entries, menus, Japanese UI, lists and Return confirmation, full screen, and the bottom toolbar.
- Images, archives, PDF, TXT/Markdown/EPUB, navigation, documents inside archives, and resuming.
- New and existing settings, script registration, settings, cancellation, restart, and filters.
- Caching, saving and export, file watching, OS-specific display-sleep inhibition, DPI, printing, and input devices.

Mark unchecked items NOT_RUN or NA with a reason; do not infer them from previous
successes. Keep automated skips distinct from manual checks that were not run.
For small changes, select only the necessary regression checks.

## macOS download path

For the final distribution, download the app through a browser and launch it from
Finder. Check the Gatekeeper warning and, if required, startup after granting an
exception for this specific app.
