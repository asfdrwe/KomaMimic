MangaMeeyaとの違い

日本語 | English

KomaMimicはMangaMeeyaに着想を得た独立した実装で、完全互換ではありません。 以下は現在確認している相違と代替操作です。将来の対応を約束する一覧ではありません。

機能 対応・相違 代替操作・説明
プラグイン・スクリプト Susie/AviSynth DLLや旧独自スクリプトの互換実行は提供しません JavaScript API 1で画像reader/filterを追加できます
未対応形式 GCA、バイナリMMT等は互換読込できません 対応形式と制限を参照してください
カスタムサムネイル 列数、寸法、間隔、名前行数、配置起点、装飾枠に対応します。原作の縮小方式全選択、JPEG間引き設定、cacheの保存形式・専用拡張子・専用保存先、原作cacheの取込は再現しません 表示と画像加工。保存済みcacheの形式・画素の原作との一致は保証しません
ソートメニュー 現行の自然順・名前・種類・サイズ・更新日時・格納順・Unicode順・ランダムを使い、逆順は共通の切替です。原作の全パス順項目を個別再現しません 下記の保存仕様を参照してください
フォルダブラウザー 2ペインはWindowsで仮想デスクトップ、macOS/Linuxで仮想「場所」が最上位です。ShellやFinderの全機能を再現するものではありません 任意の1ペインはWindowsでPC、macOS/Linuxで/。操作方法
自動再生の時間設定 MangaMeeyaは専用の再生設定ダイアログ、KomaMimicは環境設定の「表示」で指定します 下記の設定場所と再生操作を参照してください
設定移行 対応するINI項目だけを変換します。未知の項目・値を推測して適用しません。原作のmouse/gamepad、プラグイン、外部プログラム、パス・履歴等はこの操作では移行しません 設定の取り込みのプレビューで実際の対象を確認してください

サムネイルサイズの単位

KomaMimicのカスタム幅・高さ・間隔は論理ピクセル指定であり、DPI値ではありません。Qtの高DPI表示では、設定値と実際の描画画素数は画面倍率によって異なる場合があります。MangaMeeyaにも幅・高さの数値設定がありますが、同じ値を入力しても同じ見た目や保存画像の寸法になるとは限りません。MangaMeeyaの内部のDPI対応はこのガイドでは保証しません。詳細は表示と画像加工を参照してください。

自動再生の設定場所とページ送り

アプリ 時間の設定場所
MangaMeeya 「ブックリスト → プレイリスト再生設定…」で開く「再生設定」ダイアログの「表示時間」
KomaMimic 「環境設定 → 表示」の「自動再生の間隔（ミリ秒）」

KomaMimicの再生・逆再生・一時停止・停止は「ブックリスト → ページ・プレイリストの再生」から操作します。 時間の指定は上記の環境設定で行います。

通常の自動再生でページを送る際は、MangaMeeya・KomaMimicとも手動の「次に進む／前に戻る」と同じ扱いです。 KomaMimicでは見開きや本の末端での動作など、通常のページ送りの設定に従います。

ファイルソートと保存

「ツール → ファイルソート」と「環境設定 → 表示」の並び順は、表紙一覧と画像の読書ページで共用する既定設定です。 方式と逆順を保存し、再起動・設定スロット・KomaMimic設定のエクスポート/インポートで復元します。 元のファイルや書庫の内容は変更しません。ソート時は選択中のファイル・読書ページを識別して維持します。 設定の読込をキャンセルした場合は変更しません。

初期値は自然順・逆順OFFです。既存の表紙一覧の明示的な設定値も引き継ぎます。 次に開く画像や書庫にも適用しますが、TXT・Markdown・EPUB本文の章やページをファイル名順に並べ替える機能ではありません。 白紙追加・ページ削除・分割等で編集した構成は自動ソートで崩しません。明示的な並び替えは可能です。 取り込んだリストに本ごとの並び順がある場合は、開く際にその指定を優先します。開いた後の明示的なソート変更は可能です。 読書中の並び替えをUndoしても、保存した既定設定まで初期化する操作にはなりません。

通常フォルダの表紙一覧ではフォルダを先に表示します。種類・サイズ・日時が同じ場合は自然順を使います。 格納順は書庫ではエントリ順、通常フォルダではOSの列挙順となり、OS間での一致は保証しません。 ランダムは方式だけを保存し、並びそのものや乱数seedは固定保存しません。開き直しや明示的なランダム選択では新しい並びとなり、単なる再描画では再シャッフルしません。 逆順は現在のランダムな並びを反転します。フォルダ優先は維持します。

読書下部のファイル名とサムネイルの付加連番は、既定で非表示・必要なら有効化できます。 これらの改善済み項目を未対応とは扱いません。設定・cacheの保存方法は設定とキャッシュを参照してください。
